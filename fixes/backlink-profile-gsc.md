## Verdict

- **Profile is thin:** ~33 referring domains / 77 links is weak for a competitive international law niche.
- **Concentration risk:** ~87% of external links point only at the homepage.
- **Quality mix:** a handful of real directories (HG, BCG Search, ProvenExpert, GoodFirms, Lawzana, LinkedIn) + own `.av.tr`, diluted by forums, PR wires, and Yandex surfaces.
- **Biggest SEO gap:** cornerstone service articles have almost zero external links.

## Practical priorities

1. **Earn links to money pages** (divorce, company for foreigners, deportation, debt recovery, criminal record) — not only homepage.
2. **Keep / grow directory & review profiles** already working (HG, ProvenExpert, GoodFirms, Lawzana, avukatistan).
3. **Ignore or don’t chase** releasewire / distrobird / timebusinessnews-style wires.
4. **Use `cindemir.av.tr`** as a clean brand property that already links over.
5. **Internal:** finish routing equity away from `?lang=ru` / `?lang=zh-hans` toward canonical language URLs (plugin v2 already started this).
